How it works

Four minutes of ritual,
or two seconds.

Without DevMirror ~4 min

  1. Hunt for your IP

    Run ipconfig, scroll past Docker, WSL and VPN adapters to find the right IPv4.

  2. Thumb-type it

    Key 192.168.1.143:5173 into a phone keyboard, flipping to the number row for every dot.

  3. Wait on a typo

    One wrong digit, a 30-second spinner, then ERR_CONNECTION_TIMED_OUT.

  4. Do it again tomorrow

    The router hands out a new IP and your bookmark goes stale.

With DevMirror ~2 s

  1. Same Wi-Fi

    Put your phone and your dev machine on the same network.

  2. Open the app

    Your running servers are already listed, labelled with each page's <title>.

  3. Tap

    It opens in Chrome Custom Tabs: a real mobile browser with real rendering.

Subnet auto-discovery

Sweeps your local network for dev ports the moment you open the app. Nothing to configure.

Page titles, not port numbers

Each server is labelled with its live HTML <title>, so you can tell your three :3000s apart.

Opens in a real browser

Launches in Chrome Custom Tabs, so what you see matches what your users see.

USB when Wi-Fi won't cooperate

Forward the port with adb reverse and connect to 127.0.0.1. Works on locked-down office networks.

Recent servers

Reconnect to anything you've opened before. Swipe to forget it.

Dark & light

A quiet monochrome UI with monospace details, in whichever theme you work in.

Setup

You're one flag away.

Most dev servers only listen on localhost by default. Tell yours to listen on the network and DevMirror will find it.

npx vite --host

Or add --host to your dev script: npm run dev -- --host. Vite guide →

npm run dev -- -H 0.0.0.0

Next.js serves on port 3000 by default. Next.js guide →

ng serve --host 0.0.0.0

Angular serves on port 4200 by default.

python manage.py runserver 0.0.0.0:8000

If Django rejects the request, add your machine's IP (or '*' while developing) to ALLOWED_HOSTS.

flask run --host=0.0.0.0

Flask serves on port 5000 by default.

Click Go Live in the VS Code status bar.

Live Server usually accepts connections from your network with no changes. Live Server guide →

adb reverse tcp:5173 tcp:5173

Enable USB debugging, plug in, forward your port, then enter 127.0.0.1 and the port in DevMirror's connect bar. No Wi-Fi needed.

FAQ

Questions, answered.

How do I view Live Server on my phone?

Connect your phone and computer to the same Wi-Fi, click Go Live in VS Code, then open DevMirror. Your Live Server appears in the list, so tap it. Without the app, type http://YOUR-COMPUTER-IP:5500 into your phone's browser. Full Live Server guide.

Why doesn't localhost work on my phone?

localhost (or 127.0.0.1) always means "this device". On your phone it points at the phone itself, not your computer. You need your computer's local network address, like 192.168.1.14, and DevMirror finds it for you. How to open localhost on a phone.

My server isn't showing up.

Check three things: the server is listening on 0.0.0.0 (see Setup), both devices are on the same network (guest Wi-Fi often blocks device-to-device traffic), and your firewall allows the port. Windows asks the first time a server starts, so choose Allow on private networks. You can always type the IP manually or connect over USB.

Which ports does it scan?

The usual dev ports: 80, 443, 3000–3002, 4000, 4200, 5000–5001, 5173–5174, 5500–5502, 6006, 8000–8002, 8080–8085, 8888 and 9000. Anything else, enter manually.

Does DevMirror send my data anywhere?

No. There's no account, no analytics and no ads. The app only talks to devices on your local network, and your recent servers are stored on your phone.

Is there an iOS version?

Not right now. DevMirror is Android-only. On iPhone you can still use the manual method in the localhost guide, and if you'd use an iOS app, tell us.

Android says the APK is from an unknown source.

That's expected for apps installed outside the Play Store. Allow your browser to install apps when Android prompts you, then open the downloaded file.
