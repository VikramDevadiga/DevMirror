TRY IT WITH YOUR PROJECT
  1. Connect your phone and computer to the same Wi-Fi.
  2. Start your dev server so other devices can reach it:
    Vite (React / Vue)
    npx vite --host
    Next.js
    npm run dev -- -H 0.0.0.0
    Django / Python
    python manage.py runserver 0.0.0.0:8000
    VS Code Live Server
    Click "Go Live"
  3. Go back to DevMirror and pull down to rescan. Your server appears under Live Servers.
